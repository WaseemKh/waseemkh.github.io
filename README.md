# Waseem Sabra Portfolio

Static portfolio for Waseem Khalid Sabra, Senior Full Stack .NET Engineer.

## Publish on GitHub Pages

Target account: WaseemKh
Repository: waseemkh.github.io
Target URL after publication: https://waseemkh.github.io/

1. Create a public repository named `waseemkh.github.io` under `WaseemKh`.
2. Upload these files directly to the repository root. `index.html` must be at the root, not inside another folder.
3. In repository Settings > Pages, select Deploy from a branch, then main and / (root), and Save.
4. Wait for the Pages deployment to complete and verify the published site.

No build command or dependency installation is required. The source uses HTML, CSS and browser JavaScript.

## Files

- index.html: profile content and links
- styles.css: layout and responsive styling
- app.js: menu, workflow illustrations and case-study dialogs
- assets/: original portrait, favicon and downloadable CVs
